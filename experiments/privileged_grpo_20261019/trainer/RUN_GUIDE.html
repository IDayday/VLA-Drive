1. 推荐运行方法

本地已有 TRAINING.confirmed.json、F_POLICY.confirmed.json 和 prepared_v4/。默认读取assets.local.json，输出自动放入全新runs目录；不必填写epoch、seed或预算环境变量。先执行plan/check查看报告。

cd /mnt/workspace/DriveExpert/20261019-privileged-grpo-full/trainer_v1
PYTHONDONTWRITEBYTECODE=1 bash launch.sh plan
PYTHONDONTWRITEBYTECODE=1 bash launch.sh check --deep
# 只有可用且获分配的设备通过预检时，以下命令才会启动计算。
PYTHONDONTWRITEBYTECODE=1 bash launch.sh run

bash launch.sh不带参数也等价于run。执行顺序：预检 → 三范围真实冒烟 → 1405场景C/F多模态位置检查 → 多卡时的目标并发冒烟 → 五输入前测 → 33副本训练 → 固定终点后测 → 配对统计。不会提交DLC、安装软件、修复驱动或接管其他作业。

# 明确输出目录和设备；设备需属于本任务。OUT必须不存在。
bash launch.sh run --assets assets.local.json --training TRAINING.confirmed.json   --prepared prepared_v4 --devices 0,1 --out runs/formal_new

# 只核查CPU侧资产与输入，不将结果当成GPU可运行证明。
bash launch.sh check --cpu-only --out runs/cpu_check_new

plan只作配置与工作量检查，状态PLAN_READY不证明设备可用。check --cpu-only为CPU_READY；完整设备检查成功为READY，但仍须在run中通过真实模型门槛。检查失败为NOT_READY，退出码2。默认输出目录含UTC时间和PID，每次独立；工具会打印预检结果。

这是B/C/F/E共同的修正请求；轨迹是8个ego后轴局部路点的x/y/yaw，单位米/弧度。输入轨迹、评分和guidance始终来自原冻结Base，不随模型更新。E允许事后反馈和GT对齐，是特权上限。A也改变了后缀，不能要求复现旧后缀SFT输出；必须重跑清理协议前测。

4. 环境、设备与输出位置

使用已配置研究环境。来源环境记录：Python 3.10、torch 2.4.0、transformers 4.57.0、numpy 1.26.4、scipy 1.11.4、accelerate 1.5.2、omegaconf 2.3.0、Pillow 10.1.0、shapely 2.1.2；模型还有原项目依赖，这不是充分的安装清单。不擅自安装或修改公共环境。

entry.py为HF、torch、XDG、triton、numba、matplotlib和TMPDIR设置任务内cache；各run另有独立cache。共享源码与数据只读，不生成字节码。实际输出由--out控制，assets中的output_root不会替代它。

默认--devices auto只选当前可见且≥95%显存空闲的卡，不保证其权属；操作者应在本任务分配的环境运行。指定--devices时使用父环境物理序号、逗号分隔无空格；不要再用CUDA_VISIBLE_DEVICES给entry.py重映射。子进程每副本只看到1张卡。没有空闲/可用卡就拒绝启动。

参数与AdamW状态为FP32，VLM内部BF16 autocast，动作头FP32；训练还加载冻结参考副本。旧协议冒烟显存约31.4/50.9/55.1 GiB（动作头/VLM/联合），快照约18.4/28.8/35.4 GB，仅供粗略预留，不能代替新协议实测。注意主机内存、磁盘和并发大权重读取峰值。

11. 统计与结果解释

run结束自动调用analyze.py生成JSON。每场景先平均3×8候选，后测再平均训练seed；按实际17个源记录聚类bootstrap5000次，保留scene-weighted均值，另列各seed后测。区间不是训练seed层级置信区间。主比较difference_in_gain；辅助比较未校正。

分析拒绝阶段身份不同、重复arm/seed、缺组/候选及前后噪声不配对。f_sensitivity单列严格/例外子集，空子集为null，不生成虚假均值；本轮测试141全严格。训练监测/在线记录的F标签供训练侧单列统计，不把不同难度子集直接当因果对照。

PDMS为0–1：NC×DAC×(5EP+5TTC+2CF)/12，DDC另报。每候选独立fresh reference+candidate；归一化8×4动作decode为8×3后轴局部轨迹，yaw=atan2。通过要求PDMS≥.8且NC/DAC/TTC=1；修复要求高于原挖掘Base预测且上述安全项全1，基准仍属旧后缀，应标明来源。

全零、全一、其他同分分开记录；std<1e-6优势置零但保留KL。Oracle@8是候选上限，不是最终selected；本入口没有额外scorer/router。均分提高不等于探索改善，几何差异不等于驾驶互补，只评失败子集不能证明正常场景保留。

12. 常见错误

现象处理
NOT_READY / No usable accelerator当前执行环境没有可访问设备；在获分配的可用研究环境运行，不改系统驱动/代理。
No idle visible acceleratorauto未发现显存≥95%空闲卡；核实资源后用--devices，不接管其他任务。
Input/Parameter protocol mismatch配置与源码不一致；保留v3输入和history-frozen-v2，不跨协议恢复旧断点。
Full F coverage / policy mismatch重新核对prepared_v4、confirmed配置与F例外政策，禁止手改PASS或删样本。
