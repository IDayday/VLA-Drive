# Stable NAVSIM v1 training version: 20260801_193514

The `main` branch uses the training source saved by the completed
`navsim-v1-formal-16gpu-bz2-ga1-flashattn-20260801_193514` experiment.

## Verified result

- 100,000 optimizer steps completed with finite weights.
- NAVSIM v1.1 PDMS: `0.8915715213` (`89.2` at the paper's precision).
- NAVSIM v2 EPDMS: `0.8863148336` (`88.6`).

## Formal training contract

- One node, 16 accelerators.
- Per-device batch 2, gradient accumulation 1, effective batch 32.
- BF16, FlashAttention 2, DeepSpeed ZeRO-2.
- Wan and PPD features are pre-cached and staged to node RAM when available.
- The Qwen path remains online and skips the unused LM-logit projection.
- Aggressive post-193514 fused-kernel changes are not enabled in this version.

Run the non-interactive DLC entrypoint with:

```bash
bash /mnt/zhangt_workspace/project/DriveDreamer-Policy/training.sh
```

The inference launcher defaults to `QWEN_FORWARD_MODE=auto`. This is required
because 193514 was trained with the optimized normalized Qwen hidden-state path;
using the legacy hidden-state path produces invalidly low evaluation scores.

The later experimental implementation is preserved on the Git branch
`archive/post-193514-optimizations-20260804` and is intentionally not the main
training implementation.
