## loss如何换算

ActionCodec对x/y/heading的反归一化斜率分别是33.37米、21米、1.765弧度。因此每个通道的归一化MAE为0.001时，分别对应纵向3.337厘米、横向2.1厘米、航向0.10113度。偏置在求差时抵消。

训练标量是8×3有效元素的平均绝对误差，乘总loss系数10之前。同一批有效三通道等权时：

`L = (MAE_x_m/33.37 + MAE_y_m/21 + MAE_heading_rad_unwrapped/1.765)/3`。

当前有效训练日志没有保存三个独立通道的MAE，无法从0.003680这一个数还原三个实际误差，也不能将三个不同单位混成一个厘米值。训练输入是GT与噪声混合的中间状态；下表是从纯先验经完整十步ODE得到的最终输出，两者不是同一误差读出。
