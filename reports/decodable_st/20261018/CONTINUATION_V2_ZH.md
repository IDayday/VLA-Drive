状态时间：2026-10-19 00:12 UTC。此前全部数据与负结果保留；本页增量记录新实验，不能与旧配方混作同一次续训。原始数值见 [CONTINUATION_V2_RESULTS.json](CONTINUATION_V2_RESULTS.json)，原始收据校验见 [CONTINUATION_V2_EVIDENCE_SHA256.json](CONTINUATION_V2_EVIDENCE_SHA256.json)。

## 已完成的新证据

1. **原有容量能保留更多教师信息。** 使用已经登记过的 32×32 patch / 2048 维线性瓶颈，只更换训练集拟合的 PCA 初始化与求解方法。48 个训练日志拟合，另外16个训练日志留出，不使用开发或 Navtest。留出教师一致性 IoU 为 **99.6335%**，教师占用漏检率 **0.1916%**；近场 IoU 99.3610%，原生低置信边界区域98.4315%。同容量此前 Adam 结果仅91.63%，不能再把这一差距全部归为信息容量不足。

   原生 context 不由稀疏样本补零重建；教师在完整 context 上解码。PCA 的潜变量白化和逆变换成对使用，送回原 decoder 的分布没有被任意归一化。固定 decoder 参数不变。FP64 算子测试另核验了轴顺序、输入梯度及白化重参数化等价性。以上仍然是**教师预测保真代理**，不是相对真实占用的质量保护线。

2. **查清并校准辅助梯度失衡。** 固定8个训练场景、同一共享 LoRA_B 参数上，DINO / 空间 feature / decode 的原始梯度范数中位数分别为0.003470 / 5.496817 / 11.794965。按预定的一次校准规则，每项新任务的加权中位梯度不超过DINO的0.5倍，选定共同权重：DINO=1，feature=0.0003156563，decode=0.0001471056。不按开发PDMS为各组单独调参。

3. **独立正占用与坐标检查。** 使用64个真实训练场景的131072个前视FOV支持 LiDAR 击中点，沿用原始外参、畸变与成熟坐标工具，没有拟合高度平移。教师击中召回92.1356%，PCA重建92.1463%。零context召回反而99.9596%，表明“几乎处处判占用”就能在正例单指标上得高分。因此这个检查支持击中对齐和未见压缩破坏，**不能验收占用precision、IoU或free空间能力**。FOV支持不等于遮挡可见性。

4. **SGDrive默认物理horizon已得到来源证据。** 固定HF revision的官方训练JSONL中，64个独立训练日志与原始时间戳核对：LiDAR列表约为当前/1/2/3/4秒，最大误差0.01016秒；发布代码默认future_idx=1，所以发布默认协议约1秒。发布checkpoint是否采用环境覆盖仍无记录，不能把默认协议证据写成权重确切horizon已验收。没有将QA真值答案送入预测前缀。

5. **S0 FP32重放保持原行为。** 官方DeepSpeed重构的完整FP32 master只生成一次，后续严格加载全部参数。8个既存canonical场景、相同FP32/TF32关闭/10步/scene seed42，轨迹最大差为0。它是权重恢复资产，不是视觉feature cache。15项相关CPU测试通过；这不代替完整训练或科学效果验收。

## 目前能与不能说明什么

- 已有证据支持：上轮空间结果受不充分的瓶颈优化和新任务梯度失衡影响，尚不能据此否定Qwen表征学习方向。
- 仍未证明：新学生已学会空间、LoRA胜过同容量冻结读出、时间知识可靠、规划PDMS有收益。
- 旧dev16的LoRA与冻结版本为42.33%/41.84%教师一致性IoU，差异区间跨零；这个旧负/不确定结果不会被压缩上界替代。
- 可靠observed-free/unknown仍缺物理射线原点与首回波来源。合并点云的identity外参不能代替五个物理LiDAR的发射原点。OpenScene的可选invalid-mask资产也未在本地找到，不能把其稀疏label补零视作可靠free。
- 时间教师原任务的GT轨迹走廊、缺点置空及ego(t0)问题仍在。尚未进行T-driving适配、persistence有效动态区域对照、时间蒸馏或完整P2/P3。
