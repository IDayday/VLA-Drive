# A/B 固定终点完整 Navtest：结果与研究判断

2026-10-18，四个当前终点、两种单候选 ODE 网格、官方 PDMS v1.0/v1.1 均已完成全量评价和配对校验。**B 换头后没有明显丢失 SFT 均分，但本轮 RL 尚未在主协议 v1.1 上形成可靠增益；A 的原生部署显著退化。92 分目标未达到。** B 在 v1.0 上有正增量，不能说所有版本都无收益；同时两组的 NC/TTC 均有退化，不能用较高版本掩盖安全代价。

完整数值、分项、低尾、配对区间、成本和输入 hash 见[已封存结果包](final_navtest_20261018/README.md)及其 [COMPLETE](final_navtest_20261018/COMPLETE.json)。包内摘要经过完整人口验证，v1.1 均分、安全事件数与独立 canonical 分析相互核对；本说明没有重新推理或评分。

## 评价人口与比较对象

- 每个模型/网格均为 **12,146 场景 / 136 logs**；训练 seed42，推理 seed2101。
- A：保留原 DDP 动作头，完成新的时间分布/加权 FM SFT20k，再进行 R_SOURCE RL20k。
- B：迁移 standalone ActionDiT，完成 SFT100k，再进行同配方 R_SOURCE RL20k；不加载 Wan/MoT 或公开 SimWAM 权重。
- E_NATIVE 是原十步均匀 ODE；E_SHIFT5 是十步 shift5 ODE。每次只生成一条轨迹，无搜索、scorer 选轨或 best-of-two。
- 同一请求轨迹分别进入两个锁定官方版本及各自参考缓存。训练仍使用源 10:5:2 读出，正式 PDMS 为各版本的 5:5:2 入口。
- 固定终点与权重在 Navtest 前锁定，没有按本次 Navtest 选择检查点。Navtest 历史上已多次使用，不能称完全盲测。

因此不能写成“所有安全项都下降”：DAC 上升，NC/TTC 下降。原生 G+/G−（逐场景原始 0–1 得分差的正/负绝对值总和）为 A **191.928271/323.054969**、B **217.370554/221.985834**；这些是累计得分量，不是百分点。

B 原生实际模拟终点前向位移均值从 19.4774m 增至 19.9290m，平均分段速度从 5.0561 增至 5.1705m/s；A 分别为 19.5705→20.0723m、5.0818→5.2047m/s。两条路线都更向前、更快，并增加 NC/TTC 失败。这支持进度与安全权衡的解释，但不是已完成因果归因。

请求轨迹离散 jerk RMS 的均值也增加（A 0.5864→1.7398，B 0.3904→1.3629）；这是请求轨迹的描述性量，不是官方模拟 Comfort，后者仍为满分。到达自身路径 90% 的时间不能当作到达相同目标的时间，不用它宣称更快完成同一任务。

## 本次扩容、成本和退出状态

授权空余资源实际扩到 **40 张唯一 GPU**：A 的 SFT/RL 各8张，B 的 SFT/RL 各12张。旧8个 worker 在场景边界退出，旧结果未覆盖；12,790个模型×场景的已完成结果校验后复用，扩容后新完成35,794个。40个新 worker 均通过原始观测入口一致性检查并已退出，四个 CPU 调度/分析 owner 也已退出，未触碰其他任务。

扩容首 worker 启动至最后 worker 结束为 **35.4118分钟**，包含错峰加载；它不是从最初8卡任务开始计的总 wall，也不含其后完整配对校验和报告时间。每模型从原任务首次开始到最终 worker 结束约69.88–75.01分钟。A 稳态场景吞吐约原来的4倍、B约5–6倍，是实测推理阶段比较，不是整个研究成本加速倍数。

四模型×两网格共有 **97,168 条逻辑单候选轨迹**；计入48条原始入口检查，实际推理共 **97,216 次**。v1.0复用同一请求，共97,168次已提交评分调用，没有为换评分版本重新跑模型。累计共享 GPU worker wall 为 **20.953951小时**，包含旧/新调用；不能写成独占 GPU 计算时间。加载、前向、评分等待、每次 invocation 和迁移成本见[成本账本](final_navtest_20261018/results.json)。中断评分未记下的在途计算明确为未知，不能补0。

推理数值源码仍为 `45d2318d2dec265583860a26f891d8b79bb6068a`；扩容只修改分片、资源调度与汇总，没有修改 actor、精度、seed、采样器或评分公式。新增分片/存活校验/成本/封包共20项针对性测试通过，并实际执行了完整数据路径。原始载荷不上传，公开[GPU完成聚合](final_navtest_20261018/GPU_completion_aggregate.json)绑定私有逐 worker 收据的 SHA。

另有一项历史文字更正：实际两个评分版本均使用 ddp 解释器的 scipy1.11.4 / shapely2.1.2 / nuplan-devkit1.2.2，原文曾误写为另一个未使用环境的版本。已核对实际 import 与协议 hash，见[更正证据](PDMS_runtime_documentation_correction.json)；没有改环境或重算轨迹以制造一致。

## 当前结论与下一项最小改动

实现与数值验收支持本轮确实训练并评价了登记的源配方，不能据此保证算法一定提分。此次扩容与双版本校验没有发现新的 actor 数学变化，既有正常结果保留；源概率裁剪和部分随机步骤仍是已说明的经验代理，不宣称完整混合链的无偏策略梯度。

现有证据排除了“B换头先丢失了大幅SFT能力，所以RL无从谈起”的强解释，也不支持“没有非零优势所以更新无效”。它没有排除奖励偏好、弱纵向锚定、困难人口偏好和部署投影/泛化共同造成安全退化；不能直接归咎 Flow Matching 本身。

下一项优先验证 **B 上仅把训练读出10:5:2改为canonical5:5:2**：保留同一SFT、困难人口、LoRA、时间网格、采样核、anchor、optimizer与20k预算，已完成B源奖励终点为控制。先用已有TRAIN batch检查优势/梯度变化，再判断正式匹配对照；本报告没有启动新训练，也没有因Navtest调多个因素。该对照检验训练奖励偏好，不能预先声称会修复TTC，更不证明其他因素无影响。复用SFT/cache，已有B训练实测约10.06小时/8卡可作为资源估算依据，实际仍需检查可用资源与吞吐；评价成本另计。

所有权重、逐场景记录、失败和迁移证据保留。完成的是本轮登记的训练与完整评价，**有效且安全的canonical RL提升目标仍未完成**。
