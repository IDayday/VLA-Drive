# 有界存储执行决定与当前事实

复用已存在的当前 DINO 缓存（629,335,619,712 bytes，约586.1 GiB），不重建多 TB 视觉/未来教师特征。未来目标按实际训练请求以冻结 FP32 教师计算，使用有界 RAM LRU；学生仍按已核实的官方执行配方训练。训练数据、监督频率、精度与样本次序不为省空间而改变。

当前全训练人口的未来目标请求清单已完成：101,592 场景、1,176 logs；请求正文及两份来源索引约0.72 GiB。它是路径/时间/来源元数据，不是教师张量缓存。可随机访问的未来请求数据库索引仍待构建，不能将请求清单完成称作全索引或训练吞吐验收完成。

768 GiB campaign 缓存上限包含已有约586.1 GiB缓存；元数据预算8 GiB，另有最多1 GiB的冻结 W 诊断包，均不意味着立即填满。checkpoint 另行预留，保留1 TiB空闲底线；不自动删除旧数据。

64场景 W 诊断已产生完整产物且计算子进程返回0，但监督器在退出时检测到自有后代，终态为 STOPPED_NO_AUTO_RETRY；之后已确认自有进程清理为0。原失败状态保留，产物须独立核验后才能供小探针使用，不重跑提取冒充首次成功。此W诊断不是全训练视觉缓存。

完整人口上的按需教师吞吐尚未实测。当前只承诺存储有界和原定义保留，不将小样本缓存热读速度冒充长期吞吐。
