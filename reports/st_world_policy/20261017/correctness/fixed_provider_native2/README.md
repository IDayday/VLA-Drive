# Fixed8 teacher provider: bounded real training and recovery review

Independent correctness review of source `8c1e3f86268ef5ed79f46d69abf33d5c9ca74bdf`.

The fixed8 provider is connected successfully to the existing trainer for the registered 64-scene, two-update SMOKE. Continuous training completed two updates. The independent split run paused after one consumed update, then resumed its own exact registered native checkpoint in a new process and completed one additional update. All invocations exited zero. This is a budget pause inside the original 20k/warmup1000 schedule, not terminal training completion.

The immediate restored-engine receipt confirms strict native load, optimizer step, FP32 master/moment layout and dtype. The initial result and initialization receipts were preserved. Provider identity was unchanged; its RAM was cleared before the original RNG restore. The next consumed IDs and next future IDs match the saved sampler cursor. An independent read of four small RNG files (101,608 bytes total) found all Python, NumPy, CPU, CUDA, noise, time, horizon and patch states exactly equal between arms at both step1 and step2. No model or Adam payload was read during this narrow audit.

The current run did not use a full live-value observer immediately after load. Dtype and shape checks are not that proof. The previously independent real official-backend observer did check all four ranks' live values exactly; `training_state.py`, `official_runtime.py`, `student_state.py` and `fp32_master_init.py` remain byte-identical to that reviewed source. The provider additions do not change the native loader, optimizer, scheduler or RNG primitives. This inherited evidence plus the new functional integration and saved-stream checks is enough for **this bounded training-wiring and functional recovery gate**. No new full-model rerun is required. A stronger claim about every current live master value is deliberately not made.

The two independently initialized runs are not bitwise numerical replicas. Their first losses, master partition hashes, samples and denominators match, but their gradient norms differ: 3.7669742107391357 versus 3.7667880058288574. This is before any resume. The second-step losses differ as well. These differences remain evidence; none is filtered, tolerated away or attributed solely to recovery.

The installed Transformers wrapper does not translate global PyTorch determinism into the FA2 backward flag. A separate, Lead-dispatched diagnostic tested the real entrypoint with fixed BF16 Q/K/V, fixed loss and reset RNG. Across 16 backwards, default FA2 produced non-identical Q gradients for both dense and left-padded cases; explicit FA2 determinism gave identical output/loss/QKV gradients for all repeats. All forwards and losses were identical across modes. Runtime was 8.055 seconds, sampled total-device memory peak 769,654,784 bytes and PyTorch allocated peak 235,696,128 bytes. These are mechanism observations, not a full-trainer unique-cause proof or a production setting change.

The first tiny diagnostic exited before any backward because its process-memory guard could not map the container PID to NVIDIA's process list. That failure is retained. The separate v2 changes only the guard to the admitted GPU UUID's total-device memory; the numerical experiment block is byte-identical. It does not claim process-memory attribution or continuously sampled whole-device peak.

Formal approval, broad deployment scale, sustained throughput and scientific effects are not granted. The provider stays SMOKE-only. The optional full cross-run comparator is prepared, not executed; it would read at least 149.46 GB and needs about 64 GiB RAM headroom for mapped file pages. It would quantify already-known A/A drift, not isolate saved-to-live restoration. No additional GPU experiment or large comparison is required for the limited conclusion above.

`REVIEW.json` binds all actual artifacts, sources, limits and evidence hashes. Previous failed evidence is preserved. This report does not approve production launch or change the production FA2 flags.
