现阶段应保留教师 **384×288 输入、18×24 原生网格**，完成既有同基底 PCA256/384 的信息、预测和规划证据对照。已有训练代理指标支持继续检查 256，尚不足以选择它为更好的规划表征。本次仅作只读分析，不新增实验或独立 gate；精确输入、源码和快照见 [EVIDENCE.json](EVIDENCE.json)。

实际两份 CONFIG 只有通道数、相应 transform identity 和独立输出目录不同：同一冻结 train-only PCA 基底、逐通道标准化、不白化，W48/view、K96/view、教师精度、学生输入、FM、优化器及原 20k 时间轴均保持，均在 5000 更新处停止。PCA 统计来自 32,768 个训练 patch；“train-only”不表示覆盖了全部稀有事件。

384→256 使相同请求数下的目标/预测元素少 1/3；这不是整条模型链路或磁盘少 1/3。现有 width512 最终 Linear 仅减少 `(384−256)×(512+1)=65,664` 个参数，VLM 主干、W 和两层读出 blocks 不变。两组仍读取同一个 1024 通道 raw teacher cache，训练时投影为 256 不会自动减少已存缓存；实测训练耗时也不是严格匹配的吞吐基准。

**现有数值的含义。** 已有匹配日志审阅记录：两组每步样本、学习率和游标相同，均 159,992 次场景曝光；4501–5000 窗口 FM mean 为 384 的 0.01124150、256 的 0.01031342，下降 **8.26%**；全局梯度范数为 1.53911、2.05795，上升 **33.71%**。本次继承该审阅，不重读两份完整训练日志。小型 64-train/16-dev 教师 probe 的 depth MAE 为 256/384 的 **5.332822/5.197710 m**，small-vehicle PR-AUC 为 **0.916009/0.914696**；probe 参数数为 **257/385**，且这 16 个 dev 场景已用于历史维度选择。它们不是等容量或未接触留出集上的等价性证明。

截至 **2026-10-18 00:30:28 UTC**，256 的现有 dev exporter 为 `EXPORT_RUNNING`，尚无完整评分。384 的固定 dev1696 已完成，PDMS **90.66594/100**，51 个零分场景、0 invalid；256 尚不能与之比较。不能把训练 FM 改善称为已验证的规划/安全收益。

保留网格只保留了空间位置，通道投影仍会删除信息。PCA 优化训练分布的平均平方重建误差，而非安全效用：一个稀有因素若主要沿舍弃方向变化，即使其平均方差很低，也可能决定少量重要场景。非白化 PCA 的低特征值不等于“噪声”。当前统计的保留标准化方差为 256/384 的 82.57%/89.08%；这两项都是训练协方差统计，不能解释为相应比例的安全信息。

误差须在同一坐标和请求集合比较。现成 `teacher_channel_control_v1/channel_errors.py::paired_channel_errors` 已检查 request IDs/mask，分别给公共 256、384 的额外 128，以及零预测能量基线；256 未预测的尾部明确不是零误差。保持

```text
MSE384 = (256 MSE_common + 128 MSE_tail) / 384.
```

因此相同残差在 mean256 中的系数是 mean384 的 1.5 倍，宽度对照同时包含这一既定损失权重变化。其 `relative_sse_to_zero` 是诊断分母，不是白化或 dev 方差拟合。标准化 1024 维中的正交重建误差可分为“被舍弃信息 + 保留子空间的预测误差”；后者换算成 1024 维均值时为 `(d/1024) MSE_d`。逆变换回原通道尺度后，不能继续套用同一欧氏正交分解。

**可复用的实现诊断。** 实际 `train_world.py:462` 记录的是 `engine.get_global_grad_norm()`，不是 FM/aux 的共享梯度夹角。即使同一参数点，

```text
||g_FM + λg_aux||² = ||g_FM||² + λ²||g_aux||² + 2λ(g_FM · g_aux).
```

只有左侧不能确定 dot 的符号；两次训练还具有不同参数、输出头和坐标系数。先在已明确共享、两项均有梯度的参数上区分 FM、公共 256 和额外 128，后两项均用原 384 分母，并核验其梯度和等于原辅助梯度。`DDPForesight.encode_current/build_planner_condition` 确认最终 gathered W 与 action states 是同一语言输出的不同分支，不能以 `grad(FM, gathered_W)` 代替共享语言路径。若做分布式统计，应先正确合并梯度，再求 dot/cosine，不能平均各 rank 的 cosine。

已有 `calibration_measurement.py::{shared_groups,measure,gradient_summary}` 可提供随机状态保护、独立干净模型副本、无 optimizer 更新和分组统计，但只覆盖末层语言 block/W queries，且是单进程。`measure` 当前严格要求 ego/current/future/delta 四项；它**不是现成的 SP2 common/tail CLI**。在现有授权范围内落实具体诊断预算后，所需只是给这些既有诊断补上明确的公共/尾部任务接线及加和校验；不能称已测整个 LLM 或获得 ZeRO2 等价性。本次没有改动或执行该路径。

论文支持的是条件性顺序。DINO-Foresight 的 PCA 消融和损失消融见全文附录 A.1/A.5：Table 10 的 MSE 与 SmoothL1 结果接近，不能推出稳健损失普遍胜出；固定官方源码确认逐通道标准化、非白化 PCA 和默认 `SmoothL1(beta=0.1)`。[论文全文](https://arxiv.org/html/2412.11673v2)、[固定 PCA 源码](https://github.com/Sta8is/DINO-Foresight/blob/d98f765d2b743ec90fb38bc657a39c07c7ca4ab0/pca.py)、[固定损失源码](https://github.com/Sta8is/DINO-Foresight/blob/d98f765d2b743ec90fb38bc657a39c07c7ca4ab0/src/dino_f.py)。

若尾部证据支持，既有候选 `2β SmoothL1β(e)` 在 `|e|<β` 时为 `e²`，否则为 `2β|e|−β²`。这是本项目的近零曲率匹配适配，不是原论文原样配方；直接用 β=0.1 的 SmoothL1 会把近零曲率变成 MSE 的 5 倍。β 必须绑定固定训练坐标尺度，报告线性区占比；限制残差导数并不限制网络 Jacobian 后的全部参数梯度，也不消除任务冲突。

读出头与表征可能脱节的依据是 [A closer look at the training dynamics of knowledge distillation，Figure 2 及 projector 讨论](https://arxiv.org/html/2303.11098v3)；这是诊断动机，不证明当前两层头有问题。共享任务夹角的依据是 [Adapting Auxiliary Losses Using Gradient Similarity，§3、§6 与附录 E/F](https://arxiv.org/html/1812.02224v2)；其局部、小步长结论不能直接推广为 Adam/ZeRO 或驾驶安全保证。当前保持原流水线，不叠加梯度干预或其他架构候选。
