usage: run_common_once.py [-h] [--arm {C1,C2,C3,C4}] [--bind | --execute]

Bind, then run ONE original COMMON_ENDPOINT pair. Lead dispatch only. No
scientific implementation: imports the reviewed fixed-pair monitor/child. This
frontend changes only fixed argv selection and 4096 completion bindings.

optional arguments:
  -h, --help           show this help message and exit
  --arm {C1,C2,C3,C4}
  --bind               Pin completed small receipts only; never runs analysis
  --execute            Lead only, one fixed pair after actual binding/review
