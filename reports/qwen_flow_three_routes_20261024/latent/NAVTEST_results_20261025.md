# 冻结生成器潜噪声策略：完整 Navtest 终点结果（2026-10-25）

**研究判断：当前设计暂无支持。** 四个学习版本在完整 Navtest 上相对共同 BASE 的均分差置信区间均包含零；L1/L3 的进度收益伴随更多安全违规，CENTER 减轻了这种退化，但没有证明净分提升。固定 std 0.7 有小幅正增益，属于推理噪声尺度控制，不是 RL 训练成功。此判断仅针对本次实现与固定预算，不否定所有潜噪声策略。

本报告按最新用户要求，只依据完整 Navtest 判断性能与方法价值。旧 DEV/TRAIN 报告保留为工程与机制诊断，其旧价值标签不再构成当前结论。新数值及逐项来源 SHA 见 [机器可读汇总](NAVTEST_results_20261025.json)。

## 统一评价与训练边界

- 每个方法均为完整 **12,146 场景 / 136 logs**，固定推理 seeds **2101–2105**，每个 seed 单候选、10 步 source shift5 ODE、canonical NAVSIM v1.1。五次推理先在每个场景内平均，再按完整 log 做 2,000 次配对 cluster bootstrap，保留场景权重；没有 best-of 或评分选轨。
- 学习版本仅用训练 seed42，每臂64 fresh rounds、B16/G16、256次真实 optimizer updates、16,384条新训练候选。五个推理 seed 不是五次训练重复；区间不包含训练 seed 或未采样推理 seed 的不确定性。
- 所有版本从同一成熟 CANONICAL50k 模型独立出发，改变24维 root 高斯分布，生成器及 buffers 全冻结。ODE 内部没有额外随机 xi。本轮是对已有有效 RL 模型的增量改进，不能据此否定之前 IL→RL 的收益。
- 完整root联合 Gaussian 概率与解析 prior KL 用于本路线，不把旧 dimension-mean denoising surrogate 当作 root 联合概率。部署与训练均通过同一 ODE 生成器，这次结果不能简单归因于 SDE→ODE 迁移。

共同协议 SHA256：`4a82a484a321096272640a2f2644f5708265690a2d16a7e51778c7e70173a095`。成熟父模型 SHA256：`cfc3a0c949237a7ff59c9b63132a0fc82ec7b7cd154160813007ac1d279fab20`。冻结生成器参数及 buffers 校验见[训练与条件性审计](training_and_conditioning_diagnosis.md)。

以下分数及增量均为百分制 PDMS 点。95% CI 是相对 BASE 的配对差区间，不是绝对分区间。

| 固定std 0.7（不训练） | 90.554548 | +0.082773 | [+0.030380, +0.141111] | 90.608144 | +0.094979 |
| 固定std 1.3（不训练） | 90.260945 | -0.210830 | [-0.283345, -0.147429] | 90.343278 | -0.169886 |

L2 和 CENTER 的五seed测试点估计为正，但区间包含零，稳定性不足。四个学习版本在 seed2101 下的点估计均为负，其配对区间也均包含零；不能挑选五seed或单seed中更高的一列来宣布成功。没有方法达到92。登记的实用尺度为0.5点；小于该尺度的正负变化已完整披露，不以阈值隐藏。

固定 std0.7 的五seed增量为 +0.082773点，区间 [+0.030380,+0.141111]；seed2101 增量为 +0.094979点，区间 [−0.007430,+0.205548]。这说明当前生成器对噪声先验尺度敏感，未说明已学到新的驾驶策略，也不构成逐场景安全保证。

## 收益与退化必须合看

G+ / G− 先对每场景五seed均分求相对 BASE 的正/负差，再对全部场景求和并除以场景数，单位为PDMS点；净收益 = G+ − G−。事件数则为60,730个配对单候选输出中的次数，不是独立场景数。NC<1（含NC=0.5）、DAC<1、TTC<1均计对应违规。

| 方法 | G+ | G− | 新零分 / 零分恢复 | 新联合违规 / 联合恢复 | 新NC / 恢复 | 新DAC / 恢复 | 新TTC / 恢复 |
|---|---:|---:|---:|---:|---:|---:|---:|
| SCALE07 | 0.283952 | 0.201179 | 86 / 129 | 144 / 239 | 37 / 51 | 50 / 80 | 100 / 165 |
| SCALE13 | 0.213959 | 0.424788 | 193 / 87 | 325 / 151 | 72 / 37 | 135 / 54 | 212 / 99 |
| L1 | 0.386877 | 0.395122 | 172 / 67 | 369 / 125 | 101 / 24 | 76 / 43 | 308 / 82 |
| L2 | 0.011785 | 0.010251 | 4 / 3 | 8 / 4 | 2 / 2 | 2 / 1 | 9 / 2 |
| L3 | 0.463664 | 0.547245 | 245 / 68 | 497 / 133 | 143 / 23 | 109 / 45 | 410 / 88 |
| L1_CENTER_V1 | 0.128155 | 0.106294 | 42 / 45 | 71 / 81 | 21 / 16 | 23 / 30 | 50 / 51 |

L1 的 EP 均值增加0.463752点，同时 NC/DAC/TTC 分别下降0.122674/0.054339/0.372139点；L3 的 EP 增加0.542800点，同时分别下降0.192656/0.105384/0.530216点。它们确实改变了输出，但新增损失抵消或超过改善，不能用进度提高宣布有效。由于 PDMS 有乘性 gate，不能把这些分项均值当作总分的线性因果分解。

CENTER 的 EP 增加0.038982点，NC下降0.007410点，DAC/TTC增加0.011526/0.001647点，联合恢复81次而新联合违规71次；净分仅 +0.021861点且区间跨零。它较少改变原策略，安全变化也较小，不能把更温和的位移全部归因于有效场景条件化。

零分事件的定义另表分开。这里没有独立建立完整 Navtest 的固定多seed安全参考人口，TRAIN512/DEV256分层不能移作测试集“原稳定高分”标签；本报告不伪报该分层结论。

| 方法 | 单次输出零分率 | 任意一个seed零分的场景 | 五seed全零的场景 |
|---|---:|---:|---:|
| BASE | 3.131895% | 504 | 276 |
| SCALE07 | 3.061090% | 443 | 303 |
| SCALE13 | 3.306438% | 618 | 243 |
| L1 | 3.304792% | 535 | 286 |
| L2 | 3.133542% | 503 | 275 |
| L3 | 3.423349% | 565 | 288 |
| L1_CENTER_V1 | 3.126955% | 501 | 273 |

固定std0.7虽然降低平均零分率，却将五seed全零场景从276增加到303，说明收窄随机分布也可能集中暴露某些持续失败。五seed均分恰为零的场景数在本数据上等于全seed零分数，但两个事件定义仍不同。普通 bootstrap 的零事件零宽区间也不代表真实失败概率为零。

## 关键对照与机制边界

以下直接配对差仅重用已完成的逐场景CSV，未新增推理或评分。区间为名义95%区间，未对多项比较额外校正。

| 对照 | 五seed Δ PDMS | 配对95% CI |
|---|---:|---|
| L1 − L2 | -0.009779 | [-0.082392, +0.063739] |
| L1 − L3 | +0.075336 | [+0.036211, +0.119493] |
| L1_CENTER_V1 − L1 | +0.030106 | [-0.041642, +0.101091] |
| L1 − SCALE07 | -0.091018 | [-0.188384, +0.000078] |
| L1_CENTER_V1 − SCALE07 | -0.060913 | [-0.120112, -0.003742] |
| L1_CENTER_V1 − SCALE13 | +0.232691 | [+0.164261, +0.318077] |

- L1/L3原版条件MLP出现学到的tanh饱和，q几乎退化为全局分布；已排查完整联合概率、零初始化与冻结合同，不是把FM误差当likelihood。CENTER用唯一批准的固定TRAIN均值中心化恢复了输入条件差异，但完整测试仍未证实净收益。详见[条件性诊断](conditionality_minimum_diagnosis_v1.json)与[CENTER独立修正](CENTER_V1.md)。
- L2联合prior KL约0.00045，L1约1.127；同LR下实际更新尺度差异很大。L1与L2无可信测试差异，加上这个混杂，无法证明场景条件化是否必要。CENTER约0.10–0.11的联合KL也更小，不能用更小退化独证条件机制价值。
- L1相对无prior KL的L3高0.075336点，名义区间为正，说明本次正则减少了相对退化；L1相对BASE仍无可信提升，所以这不是成功的RL净增益。
- 所有学习版本的点估计均低于固定std0.7；CENTER相对它低0.060913点。学习版本优于已退化的std1.3不能证明优于原先验；保留两个预登记尺度，不根据测试继续搜索更优温度。
- 本路线固定生成器，没有“教师发现→学生拟合”过程，不能据此判断学生吸收能力；完整Navtest这里只评价单轨部署，也不将有限搜索oracle推作发现能力证据。

## 当前决定

本次固定预算下，原版L1/L2/L3及唯一CENTER修正没有可信完整测试净收益，路线标签为 **当前设计暂无支持**。固定尺度0.7提供的小幅正向线索成本最低，但它是推理尺度对照；已观察其持续失败人口代价，不把它升格为训练成功或逐场景安全保持。

暂不追加训练seed、温度搜索或更大L预算。继续完成已冻结的其他两路线完整测试，保留所有L终点结果。只有出现独立机制证据和实际收益量级，再登记一个能够匹配真实q位移、排除“只是改噪声温度/更新更小”的最小对照；不能依据本次Navtest回头调P或筛掉不利方法。
