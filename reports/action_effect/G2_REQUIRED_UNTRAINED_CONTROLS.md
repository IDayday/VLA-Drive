# Two prespecified, untrained G2 controls

Implementation starts from `792b287ea251cfef0336f91443892639ef1c179f` on
`feature/effect-g2-required-controls-20261020`. It adds only `predict_control.py`,
its tests and this report. It does not change the main six training arms, G1,
official simulator/scorer or any trained model. No GPU, training or official
scoring was dispatched by this author.

`generate_control(base_physical, initial_noise, *, control, seed=42)` is the
complete model boundary. It accepts only an original physical 8x3 trajectory and
its finite original FP32 8x4 noise, plus the fixed control/seed. It has no scene
ID, GT, feedback, metric, predicted score or context input. It uses the original
`BasisSpec`, NumPy reconstruction and the same preliminary geometric screen as
deployment A, without treating normalized history ego as an initial velocity.

The two controls are:

- **RandomLocal:** select exactly one of eight prespecified primitives: early
  or late longitudinal ±0.5m; early or late lateral ±0.15m. Selection is the first
  64 bits of SHA256 over a fixed domain, little-endian seed and original
  little-endian FP32 noise bytes, modulo eight. It constructs only that one
  modified trajectory. It never simulates, scores, searches or selects a best
  proposal. No Python/NumPy/Torch RNG state is consumed.
- **FixedLateBrake:** coefficient index2 is exactly −0.5m, every other coefficient
  is zero. This is a fixed late longitudinal displacement ramp, not a claim
  that braking is appropriate for every scene. Its choice does not depend on
  noise, labels or scores.

A proposal rejected by the preliminary geometric bounds falls back to the
unchanged original Base trajectory, with the proposed coefficients, geometry
diagnostics and fallback flag retained. This screen is not a native safety or
controller-executability certificate. NaN/invalid inputs are errors; they are
not replaced with fabricated safe trajectories or valid zero scores.

The offline wrapper first reuses the actual `predict_baseline` registration, or
an explicit matching S0 `PREDICTIONS.json`. It checks the exact completed
population, ordered IDs, roles/logs/observation hashes, Base, FP32 context and
official fixed-reference protocol. The cached S0 trajectory must be byte-equal
to the admitted original context. DEV uses the fixed complete 1696 population
and never reads training repair targets. TRAIN role support retains its fixed
manifest and actual role denominator; neither path selects by outcomes.

Each output contains immutable `GENERATOR_SPEC.json`, `PREDICTION_REGISTRATION.json`
and `PREDICTIONS.json`. The generator spec records seed, all eight fixed
primitive definitions, reconstruction/constraint/source hashes and source SHA.
The registration uses its artifact as an explicit
`engineering_control_generator_spec_not_trained_checkpoint`. Each scene has
one final output, not a candidate pool or oracle. Scores are produced separately
by the unchanged `evaluate_refiner.score`, with exactly the same population,
reference context and receipt rules as learned A/B.
