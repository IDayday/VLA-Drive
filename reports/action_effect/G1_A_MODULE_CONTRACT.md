# G1 and EGR small-head mathematical contract

Implementation base: `56e706393b15f72e0d04e3f899463892938a45d9` plus the primary-source audit. This document preregisters module mathematics, not a scientific success result. Mature S0 weights, forward, normalizer, sampler and runtime are unchanged. No external scoring weights or code are copied.

## Bound inputs and outputs

`ActionEffectModel(EffectModelConfig, FeedbackLabelSpec.from_label_arrays(actual_adapter_labels))` accepts `forward(context, base_physical, modified_physical)`. Context has exactly `memory`, `ego`, `mask`: the same-call frozen W144/A8 tokens of width2048, current ego4 and True=valid token mask. Extra fields, including labels, future, IDs and scores, are rejected. Physical trajectories are rear-axle XY metres and periodic yaw radians, 8 points at0.5s. No VLM, simulator, auxiliary future generator or metric cache is owned by this module. The two trajectory arguments retain gradients for downstream training, while upstream context is detached.

All six controls allocate the same 2,749,603 FP32 trainable parameters and initialize common tensors identically from a private CPU RNG context: A `absolute_score`, B `terminal_pdms`, C `absolute_feedback`, D `delta_feedback`, E `trajectory_only`, F `shuffled_context`. Width256, 2 decoder layers, 4 heads, dropout0. A predicts each trajectory's terminal score/components; B supervises only terminal score; C predicts complete available feedback. Each absolute prediction is independent of its comparison partner. E masks the context without deleting capacity. F requires an explicit recorded full scene permutation; the trainer must choose the negative-control policy. G privileged mode is `BLOCKED_PRIVILEGED_ASSET`, because no legal privileged-feature asset is bound.

D/E/F mean is `[f(z,a,b)-f(z,b,a)]/2`; temporal effects are similarly antisymmetric. Mean is exactly zero for identical trajectories and reverses under pair swap. Event-transition logits reverse repaired/introduced classes under swapping. This algebraic inductive bias does not prove causal identification or generalization. Both orders reuse one context projection and expand along the batch dimension, without cross-candidate attention. Outputs include `mean_delta`, absolute heads where applicable, symmetric `logvar_delta`, three event-transition heads, 41x3 temporal effects and a repair logit. Variance/probability heads are diagnostic and not calibrated. An absent supervised task must be reported as untrained.

## Supervision and reduction

Names, units and valid masks come from `tools.action_effect.navsim_feedback_adapter.label_arrays`, not an assumed output width. Modified-minus-base labels require both endpoints valid. Missing first-event times are masked rather than filled with time zero. Physical scale constants precede SmoothL1: score/component1, distance20m, time4s, speed20m/s, acceleration10m/s², jerk50m/s³, yaw-rate1.5rad/s and radians pi; unsupported units reject. Present v1.1 labels include terminal components, progress metres and first-event times. Temporal flags remain unit scale1.

Startup loss is `value + .2*ranking + .2*events + .2*temporal + .05*uncertainty + .2*repair`. Value is SmoothL1(beta0.1), events are three-way cross entropy, temporal effects SmoothL1, uncertainty normalized-unit heteroscedastic Gaussian NLL, and repair BCE. A/B do not receive full temporal/event/repair supervision, and uncertainty is masked to their actually supervised terminal fields. These constants are a fixed starting recipe, not calibrated task equivalence. Every task returns a numerator and denominator. Ordinary supervision first averages valid task elements within a scene, then averages valid scenes. A valid nonfinite prediction/target fails; an absent task returns graph-connected zero with zero denominator.

For a uniformly sampled effect pair, ranking is `sum(|true_gap|*softplus(-sign(true_gap)*pred_gap/.1))/sum(|true_gap|)` over the full batch/distribution, ignoring gaps<=.01. It never divides by each scene's gap. For a comparison stream sampled proportional to absolute gap, ranking is the unweighted pair-loss mean; gap is not multiplied again. Microbatches sum numerators/counts before division. DDP uses the global denominator and compensates for DDP's gradient averaging. This requires a trainer to preserve complete-update denominators, rather than backward each locally normalized microbatch loss.

## A0/A1 shared refiner and deployment

`CoefficientRefiner(RefinerConfig)` has 2,711,824 trainable parameters. It predicts eight bounded physical coefficients through the same small backbone and a zero-initialized final layer. Both A0 and A1 use this exact architecture, initialization, data and update budget. Their difference is training guidance. Reconstruction mirrors the shared `BasisSpec`: four quintic temporal windows times longitudinal/lateral directions, with heading updated by sampled tangent change. There is no arbitrary 8x3 residual head.

The zero output is bit-exactly the Base trajectory while retaining the limiting smooth-basis Jacobian. A naive zero-branch `where` would suppress all initial training gradients; the implementation corrects the zero value with a detached numerical correction. Undefined stationary tangents are made safe before atan2. Tests check both NumPy reconstruction parity and finite differences at zero.

The generic K8 module supports all windows. The present fixed24 G0 intervention grid does not expose window1. Its A trainer must bind `active_coefficients=(True,False,True,True,True,False,True,True)`; the corresponding output/gradient columns are zero. Coefficient combinations and continuous values can remain outside the discrete simulated support; they must be marked and evaluated as composition/OOD generalization, not claimed verified solely from training support. Bounds default longitudinal2m/lateral0.6m per coefficient and are research limits, not safety guarantees.

A0 uses verified-target physical XY/periodic-yaw and coefficient supervision, plus normalized change cost0.01 and high-quality identity-preservation weight1. A1 adds scale-normalized consistency with the verified target's real effects and a predicted NC/DAC/TTC-regression penalty through a frozen, eval G1 teacher. Teacher parameters stay frozen, but gradients through its trajectory input must remain enabled. PDMS-only teachers cannot claim learned safety guidance. Introduced-event probability guidance is OFF by default; enabling it requires an explicit trained-event-head receipt and adds weight0.1. No untrained uncertainty/repair head may silently gate deployment.

`EffectGuidedRefiner.forward(context, base)` is cache-head training. `generate(observations,initial_noise)` calls a supplied audited `encode_and_plan` Base adapter exactly once. Default `deploy` does not call G1: it reconstructs and applies the shared non-simulation geometric screen, falling back to the original trajectory on geometric rejection. This screen is explicitly not an official safety score and cannot certify collision freedom. Default export excludes the teacher. Explicit `predict_effect=True` adds one learned-teacher call, and `deploy_state(include_effect_teacher=True)` binds its weights/schema; this optional cost must be measured separately. No path uses real deployment feedback, GT, LiDAR or a simulator.
