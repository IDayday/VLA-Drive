# 动作后PDMS分项预测：IL60k独立诊断

这是训练辅助head的准确性，不是部署PDMS，也不是修复器/选轨器。固定两条已评分轨迹来自IL40k与IL53k；预测器来自IL60k，全部参数冻结。当前观测与请求轨迹为输入，评分仅在输出后用于误差统计。

自然样本2048场景独立hash抽取；额外NC/DAC/TTC边界差异场景只作定向诊断，分表报告。没有新增policy rollout、scorer调用或optimizer update；Test已被历史观察。

NC=0.5等软标签保留回归/BCE统计，硬二分类单独剔除并列出数量；硬子集无双类时AUROC为null。简单accuracy必须与always-pass基线和违规recall一起读。EP按连续目标解释。

factor使用soft-label BCE，完美预测仍有目标熵下界；analysis同时列出BCE下界与excess BCE。post总训练loss=factor+0.25×NC/DAC pair，再在总IL loss中乘0.2。

完整两轨迹、自然/定向分层、pair排序和组合PDMS误差、有效分母及成本见analysis.json。组合预测是分项估计值的乘积，不能视为精确的期望联合PDMS；不能由预测准确自动推出其辅助梯度提高了实际策略。

模型、数据、只读head与评分身份和真实入口见registration_summary.json；原逐场景输出仅留本地。
