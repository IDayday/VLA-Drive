主要证据：
1. rank0 的三个 CUDA-active profiler steps 中，IO 的 GPU 无活动空档分别为234.48/238.04/257.30 ms；这些空档与主线程 apply_chat_template scope 重叠，对应 CUDA synchronize 重叠只有约0.018–0.025 ms。P0 最大空档降至6.45 ms。processor 本身仍约260 ms/次，在 P0 转移到 ThreadPoolExecutor CPU worker，不能称 processor 计算消失。
2. 三个 active markers 的 rank0 wall 合计11.358→10.107 s；全部 stream 的 GPU 活动区间并集7.519→7.076 s，活动占比66.2%→70.0%。8-rank 占比中位数67.18%→70.45%。这是3步 trace 观察，不是正式吞吐结论。
3. trace 后25011–25032各 update 的 rank-max current-stream event 中位数：Qwen current813.31→508.70 ms，vision288.22→290.82 ms；proposal376.26→382.48 ms，backward1645.23→1620.34 ms，optimizer97.10→96.77 ms。视觉 GPU event 基本不变，batch construction 包含 vision，不能把它的 host wall 减少说成视觉计算减半。
