## 与训练、DEV及梯度证据的关系

20k DEV的Native X1为94.5538，低于Canonical的94.6719；固定20k Navtest
排序相反。这说明容易的DEV TTC不能完整预测Navtest的安全/进度权衡，
不能依据单个中间开发分数删除X1。这里仍使用预登记的完整DEV及固定
20k终点，没有据此改划分、调整阈值或挑最高的Navtest检查点。

全程训练有PG组比例为99.65%，原Canonical为99.635%；零优势不是当前
主要瓶颈。X1训练随机策略更安全但进度更低；真实保存批次中纵向均值
偏移减半左右，末步PG/anchor cosine随批次由负转正。相关证据见
[四阶段梯度诊断](../../ddp_simwam_terminal_ode_20261016/X1_saved_gradient/README.md)。
这些有限batch不能证明全部收益的因果分解，但与“方向保持影响部署”
相容；没有发现新的FM符号、LoRA接入或概率重算错误。

当前证据支持：DDP的Flow策略可以通过本轮RL产生真实原ODE规划增益；
把源配方中的归一化权重直接搬到另一动作尺度，确实值得独立适配。
它不证明Flow本体无任何设计限制，也不证明模块拼接已构成充分创新。
