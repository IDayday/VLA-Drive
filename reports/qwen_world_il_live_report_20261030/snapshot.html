B · P / A / R 共用一个决策 Transformer

下载 SVG
  • 核心问题：世界推理和动作推理共享参数，是否更利于 IL 学习及 RL 适配？
  • P/A/R 共用20×1024主干，依靠方向性注意力分离信息。P固定时间，A用当前sigma，R用clean sigma0。
  • P每场景计算一次；动作每步只更新A。后置R删除，但它训练过的共享权重保留。RL时共享LoRA改变P，不能跨inner缓存当前P。

C · 独立世界流通过逐层 K/V 帮助动作流

下载 SVG
  • 核心问题：独立世界流的逐层表示，是否比单次拼接memory更能帮助动作？
  • 20×384世界流和20×1024actor一一对应；4组K/V桥接共享actor原Q/O。C/W分别softmax，用小非零gate融合。
  • R复用世界流，并读取候选actor逐层hidden；R不反向进入同次W前向。部署保留W与world→actor桥接。

共同动作与信息边界

单条8×3绝对[x,y,heading]轨迹，未来0.5–4.0秒；不是旧8×4或逐点自回归。使用源min/max编码，但actor学习的是直接clean-x L1：xσ=(1−σ)x₀+σε，σ=5u/(1+4u)。十步ODE从噪声逐步预测clean轨迹。

未来视频、GT对象、真实评分与候选标签只用于监督，不进入部署CurrentInputs。偏离真实记录轨迹的候选只监督原生模拟可得的评分/事件；不把记录中的未来视频当作其反事实未来。

四架构的统一监督

10Lx + LDINO + 0.5LWA,pre + 0.1Lobject + 0.2Ltrack + 0.25LWA,post,factual + 0.2Levaluation。后置评价包含六小分、总分、同场景排序、NC/DAC/TTC首次违规的9类时间分布；R16为8个时间位置、6个metric、2个汇总token。

当前基线则为原四辅助项，并无上述新增track/总分/时序任务。Qwen与scene的初始化一致不等于五版训练任务完全相同。

应怎样解释损失与PDMS

同一归一化误差对应不同物理量：一个单位分别约为纵向33.37m、横向21m、航角1.765rad。归一化L1不能统一换算为厘米；每horizon的GT分布也不同，时间加权已单独登记。八个点联合生成，并非前一点通过网络自回归地强制传递到后一点。

原始与V12的已完成分析显示，loss与PDMS在长时间尺度有关联，但相邻checkpoint并不单调对应。优化轨迹提高标签EP与局部扰动容差，不保证学生重建误差仍位于同一个安全邻域；其heading、横向、纵向误差与实际NC/TTC需要一起看。
