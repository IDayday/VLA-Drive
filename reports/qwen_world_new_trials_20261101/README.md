# 从问题到实际训练：新增精度与探索实验

持续更新报告仍为 `/mnt/project/qwen-world-rl-optimization-20261030/report.html`。本目录保留 2026-11-01 新一轮研究的静态证据；实时进度应读取该 HTML。

## 实际安排

H 现在有五条真实八卡训练：提前衰减、32 场景批次、历史优质行为保持、FP32 最终动作投影、四晚期加四较早期扰动。各自科学源独立冻结，均从同一 IL70、TRAIN103288、seed42 开始；不启动重复 Control 或多种子。新两臂先到 20k，沿用 warmup1000、固定50k cosine、0.1 floor、四次 inner；10k 后每2k完整 NAV。提前衰减与 Batch32 的独立调度/预算身份仍保持，不能混写成统一20k decay。

FP32 投影组只改变最终动作矩阵乘法的计算精度，当前策略、永久 IL 参考、rollout、概率重算和部署一致。原来的 `.float()` 位于 BF16 投影之后，不能恢复精度。该实验借鉴 ScaleRL 的数值精度发现，但动作回归头与 LM logits 不同，不能承诺迁移收益。权重起点相同，初始执行函数会改变，因此额外评测 native0，并将其与 RL 学习分数分开。

混合探索组将固定 G8 分成四条 W3[7,8,9] 与四条 W3[3,6,8]。每条仍是三次噪声、全组仍评分八条；保存真实候选×扰动步骤矩阵，按 ordinal slot 重算对应均值和概率，保持原 SafetyEP 全64候选优势与物理均值 anchor。没有用统一旧步骤错误套算另一半候选，也不是精确联合流密度算法或完整 Stepwise-Flow-GRPO 复现。

## 已经看到什么

旧固定 θ10k 的 TRAIN 候选重组支持探索互补：156 个历史失败场景，严格优质轨迹见证87→123，全canonical零组21→11；高对照全部仍有见证，但PG0增加39→54，成功饱和不能算失败。此处没有新模型前向、评分或 NAV 提升。

新训练已产生不同于上述重组的实际信号。首256更新、全8rank、512组4096候选中，较早扰动的2048条候选有1543条严格优质，晚期有674条；64组只有较早分支找到，40组只有晚期分支找到。两类互补在实际训练中出现，仍不能当作对 Control 的因果改善或最终部署总分。优势/PPO有效系数按分支分别记录，不把它当参数梯度范数。

历史行为保持组恢复后，2001–2200更新的400个新场景组实际发生3次退化门控。额外 fresh/history ODE查询分别400/388，相比主PG3200查询增加24.625%，按各rank真实collection汇总，没有四次inner重复计数。每rank此窗口已积累29–41个自身经过验证的历史见证。它证明机制启动，不证明保持效果已经改善 NAV。

旧 Endpoint 低LR配置在多个完整点显著落后，已合作退出并完整保存16657-inner1；Active在完整26k边界预留；Dense完成原28k阶段后预留。都保留代码、结果和恢复状态，不把资源优先级安排等同算法家族无效。G16后期同候选量比较有正证据，继续保留；同候选不等于同Adam、场景与cosine时钟。
