## 语义与有限预算

E 三种 GT 信息均为特权探针，另设 mask-only 诊断；E_NONE 与 R 单独列 camera-only 表。P_DIFF 只是同一真实标签的差异组织，并未增加独立信息。q0 与六个变体只用于函数查询，最终输出一条连续残差轨迹，不选轨、不用 PDMS 训练。

初始阶段只路由当前授权且空闲的 vla-zt/rl-zt2。保护 vla-zt2 的 G2、现有 IQE/Scorer 等任务；不使用其他任务的临时主机租期。按当前 profile 登记本轮操作性上限 100 GPU-hours（不是用户授予的无限预算）：训练/dev compact cache 44；标签与小集 GPU 检查 2；E/P/R 及关键复跑 28；固定 G70k 诊断 6；锁定终点后的提取/部署/评价 12；余量 8。每项命令必须有有限时长；实际成本接近上限时保存并报告，不暗减 epoch 或改人口。先完成缓存及诊断，再用完整小头 profile 修订各项估计，总上限不自动增加。

代码按阶段提交，运行源码 SHA 与结果归档 SHA 分别记录。当前阶段不自动恢复暂停的 G/nuScenes/旧优化目标研究。

## 后续实测与标签修正候选

全部 11 条小模型输入路径已独立完成相同 64 场景/40 update 工程学习检查（包含 E_MASK_ONLY），初始化 hash、首尾 loss、时延见 evidence/SMOKE_ALL_INPUT_DISTRIBUTIONS.json；仍不是正式结果。

未来 LiDAR 缺口会随日志自车移动。逐像素图确认：即使障碍框和其余道路很完整，车身内少量无地面回波点也使“完整车身所有点均有支持”失效。原有效性保留为 strict 对照。新标签候选只对**当前已有可靠空闲地面、未来完整框栅格为零、该未来帧有效且 LiDAR 记录未失败**的位置，延续静态地面支持。它不使用 GT ego 轨迹，不改未知对象区域，不把无回波本身当作免费空间；原 G 缓存不改。

在相同 64 场景上，未来距离有效覆盖从 0.195% 到 74.665%，重叠从 5.580% 到 91.253%；三源共同有效距离 19.294%，共同重叠 72.238%。这是静态路面假设下的标签支持适配，尚需固定 4096 子集确认；不能据此断言历史 G 分数的因果原因。严格版本和扩展版本指标见 evidence/SUPPORT_DIAGNOSIS_64.json。派生地图图像仅留在受控共享目录，不上传原图。

G 诊断统一锁定现存 **75000** checkpoint：G3 70000 的临时权重已按旧磁盘清理规则释放，而 G1/G2/G3 的 75000 原生文件都完整存在。选择发生在本轮诊断之前，不看哪组有利、不续训制造历史权重，见 evidence/G_DIAGNOSTIC_LOCK.json。

恢复 smoke：E_NONE 的模型、optimizer、scheduler、RNG 与数据位置逐位相等。P_DIFF 原严格逐位测试未通过；继续执行的最大参数差异 3.27e-7，同环境连续 A/A 为 4.24e-7，数据顺序、曝光、scheduler、RNG 精确一致。尚不能把这一项结果描述为所有恢复验证已完成；完整 moments 和输出对照仍在补齐。
