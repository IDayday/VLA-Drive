# 局部轨迹后果差异学习（2026-10-14）

本轮冻结同一个原始GT S0 100k，研究额外环境信息的价值、局部后果差异是否可学习，以及预测信息是否能转成单条轨迹的实际改善。没有恢复暂停的G/nuScenes任务，没有联合微调大VLA。

**本轮完成**：17个正式小头/关键复跑和4个条件两折读出均完成24epoch，48次开发观察、六组完整Navtest、真实图像部署验证及失败分析全部完成。最终六组各12146场景/136 logs，评分失败为0；新增成本约71.45 GPU进程小时。

主要结论：DIFF在两个新增头seed及留出logs上改善了连续后果差异误差，但没有稳定提高规划净收益。Navtest S0为89.52787；ABS42/DIFF42为89.44094/89.45057，ABS43/DIFF43为89.47232/89.42679。全部修正器均值低于S0，新增零分多于修复；相关区间并不支持“已证明等效”。下一轮优先验证纠偏训练分布和关系使用接口。
