# 本轮方法与实际实现

这是冻结成熟 S0 的增量研究。S0 的原始 GT 100k 驾驶训练、Qwen、W 和 DiT 全部共用并冻结，不是从通用底座重新训练出一个更强 VLA。历史共享基础成本为 483.481 GPU-hours；本轮缓存、小头和评估另计。正式训练源码为 `3c08240a20709b285966ce5b1dfd6d7d49be0d6c`，报告与评价工具的后续提交不是该训练源码。

## 执行链路

当前三前视、导航和合法 ego 状态经过一次原 S0 前向，得到 144×2048 的 W 与 8×2048 的 H_A。原 DiT 从场景绑定的独立噪声执行原 10 步采样，得到唯一 q0。冻结训练缓存只存这些小表示、q0、合法状态及身份；W/H_A 为 FP16 存储，在线小头前采用相同 FP16→FP32 转换，q0 始终是原 FP32。没有全视觉 DeepStack 或 dense BEV 缓存。

七条查询为 q0、沿路径法向平滑增长的±0.5/±1米偏移、±0.5秒的单调时间重参数化。SciPy CubicHermiteSpline 复用成熟插值，补当前后轴原点和合法当前速度；时间warp满足两端固定且导数为正。环境始终在实际物理时间0.5…4秒读取。离线运动学检查只屏蔽不合法变体的监督，始终保留场景和 q0。停止/低速 heading 及实际 heading 变化率也受检查。

查询不是七次 VLA 采样，也没有按分数择优。预测器读取这些位置、姿态、时间、车身尺寸与合法状态，对每个位置输出五个量：道路余量、当前障碍间距、当前几何重叠、未来障碍间距、未来几何重叠。修正器只输出一次8×4归一化动作残差，再用原动作解码得到一条 q_final；主执行和主表都使用 q_final。

`ModelInputs`、`PredictionQueries`、`TrainingTargets` 是分开的类型。camera-only入口仅接受当前图像、语言、状态和token；GT有效性只在损失侧使用。oracle入口独立，不能把特权关系当作部署结果。部署只加载一套 S0，不在线运行 G/Qwen 或地图/框查询。

## 复用与新增部分

| 部分 | 实际实现 |
|---|---|
| 当前VLA与动作合同 | 历史 `1493deda…` 的真实 DDPForesight/原10步DiT/ego encode-decode；不是报告分支的近似实现 |
| 小头基本算子 | 复用 `foresight/future_latent_head.py` 的 CrossReadout；宽512、8 attention heads、2 blocks |
| 车身/坐标/栅格 | 复用 G 的 grid/body_points/中心修正 UniAD 算子；统一后轴ego(t0)，x前y左；0.5米网格 |
| 新轨迹查询 | `trajectory_queries.py`；不从未来GT决定偏移方向、时间或保留哪一侧 |
| 新关系读出 | `consequence_head.py`；W/H_A投影后的memory与物理query交叉读取，不把W reshape为BEV |
| 新监督组织 | 同一绝对后果目标上增加六组anchor-variant连续后果差异；没有新的GT信息或人工总risk |
| 修正器 | `residual_refiner.py`；8时间query读取 H_A 与56个关系/几何memory，零初始化残差输出层 |
| 评价与恢复 | 原canonical NAVSIM v1评分；复用原RNG工具并保存optimizer/scheduler/epoch/offset/曝光；原严格恢复失败及A/A证据保留 |

预测器总参数7,628,805；各E/R修正器8,162,308。相同seed的ABS/DIFF初始参数hash相同，各E输入组的修正器初始hash也相同。query-only独立训练相同小头主体，memory改为物理query，不读取W/H_A；其约105万参数视觉投影不参与前向，不能称有效参数完全相等。E_NONE保留空关系通道和相同参数清单，但空输入也会造成部分权重没有输入梯度。query-only仍从S0生成的q0间接获得场景信息，不是“完全没有视觉信息”的探针。

## 标签与已知近似

三类后果为完整车身最小道路有符号余量、完整车身障碍有符号间距代理和几何重叠。道路取已有SDF；障碍间距取框级occupancy的SciPy EDT，并检查更近未知区域。距离裁剪±10米，Smooth L1采用固定5米尺度；栅格近似不是精确多边形穿透深度。重叠不是官方责任碰撞，sigmoid不是校准概率。

三种环境源使用同一地图、车身和坐标：CURRENT静态保持，CV使用当前 `anns.gt_velocity_3d`，TRUE_FUTURE使用统一ego(t0)下日志未来框。CV为特权当前状态探针；速度无未来差分补齐，缺失采用显式零速回退与计数。

旧严格标签的未来LiDAR缺口在车身查询上造成极低距离支持。本轮独立标签版本只将当前已有可靠空闲地面、未来完整框栅格仍为空、有效未来帧且无高度记录失败的同一xy延续为静态路面支持。不覆盖旧G缓存，不填未知对象，不用GT ego轨迹推定空闲。这是静态表面假设，相关严格/扩展结果和覆盖单列。

所有GT信息组使用三种环境源有效性的共同交集；另外训练E_MASK_ONLY辨别特权mask的作用。未来标签有效性与当前相机可观测性分开。当前视锥检查只投影地面车身点到原三视图ROI，不知道遮挡与复杂路面高度，不能将它当可见性真值。

## 匹配比较

| 组 | 输入/监督差异 | 可部署 |
|---|---|---|
| E_NONE | H_A、q0、相同查询几何，空关系 | 是 |
| E_CURRENT_GT | 额外真实当前关系，未来槽用当前保持 | 否 |
| E_CV_GT | 当前关系及当前状态恒速外推关系 | 否 |
| E_FUTURE_GT | 当前关系及真实日志未来关系 | 否 |
| E_MASK_ONLY | 只提供共同GT有效性，关系值置零，独立训练 | 否 |
| P_ABS | 三个连续通道Smooth L1、两个重叠通道BCE；各通道按有效元素/场景归约后等权平均 | 关系头 |
| P_DIFF | 与ABS完全相同，再加六个q0-变体对的连续差异Smooth L1，lambda=1 | 关系头 |
| P_QUERY_ONLY | 独立训练，不读取W/H_A；保留物理query/合法状态 | 能力控制 |
| R_CURRENT_PRED | 冻结P_ABS，使用预测当前关系并复制为未来参考 | 是 |
| R_FUTURE_ABS | 同一个冻结P_ABS，使用正常预测的当前和未来关系 | 是 |
| R_FUTURE_DIFF | 冻结P_DIFF，使用其正常当前和未来预测 | 是 |

P_DIFF只对连续量添加差值回归，离散重叠变化用于评价，没有额外事件差分loss。绝对目标保留，差异按有效配对归约，不随pair数量放大。差异梯度在固定4096随机初始化检查中约为绝对项的0.00048倍；按预登记保留lambda=1，没有依据开发PDMS放大它。

R从训练首步就读取相应P预测，不用GT训练后再替换。P保持冻结，refine不能把可解释关系改成任意latent。R_CURRENT与R_FUTURE_ABS共享一个训练过未来任务的P_ABS，因此该比较检验执行接口上未来预测的增量，不隔离未来监督对编码器训练的因果作用。

## 训练与判断边界

共同24epoch、101592场景、batch128/micro16、FP32、AdamW lr1e-4、weight decay0.001、clip1；一epoch warmup后cosine到0.1倍LR。每个epoch每个原始场景只曝光一次，两个场景绑定q0 seed42/43按固定规则交替，不当两倍场景。6/12/18/24epoch作开发观察，主比较用共同终点。seed43复跑ABS/DIFF预测器和对应未来修正器，并按已登记的关键复核增加E_NONE/E_FUTURE_GT；S0底座仍只有一个训练seed。正式共17个完整人口小头。另因P训练/开发预测差距触发两折读出控制：ABS/DIFF各两个按训练logs切分的24epoch模型，只用于固定4096训练场景的留出预测检查，没有重训R或把开发集并入训练。

关系绝对误差、关键pair误差、场景依赖与规划PDMS分别回答不同问题。旧G75k诊断发现G3整体场误差有改善，但关键pair优势的log区间跨零，不能推断“局部采样什么也没学到”。冻结S0训练人口的q0远比开发集接近GT，也可能使修正目标分布不匹配。任何oracle无收益都需同时检查这些边界、有效覆盖和学习曲线，不能直接否定世界信息价值。

规划主表把camera-only与特权信息探针分开，报告NC/DAC/TTC/EP/Comfort、q0/q_final、旧零分修复与新增零分、原高分退化。误差区间按log聚类；新增头seed或proposal seed不等于独立S0训练复跑。Navtest在方法/共同终点锁定后统一执行，历史Navtest已被多次观察这一限制仍然存在。
