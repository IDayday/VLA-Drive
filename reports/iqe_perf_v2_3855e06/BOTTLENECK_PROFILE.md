Improving visual compute can expose CPU loading next.

All643 trainable tensors had gradients on this observed window. `find_unused_parameters=True` stays enabled: ordinary batches alone are insufficient to authorize changing missing-label/tail behavior. No global static_graph change was made. Language vocabulary head is already bypassed, use_cache=False already applied, and auxiliary CrossReadout already uses need_weights=False; none is claimed as new work.

PyTorch2.5.1+cu124's `adamw.py` lines754–778 selects foreach for eligible CUDA tensors when fused/foreach are unspecified. P1 compares that actual default against explicit fused=True, preserving group/order/hyperparameters and loaded moments. No claim that the old optimizer was a Python parameter loop.

Pure-compute compile is deferred: this trace supports addressing frozen visual and recomputation first; it does not justify recompiling the whole dynamic pipeline. No graph breaks are reported because these trials are eager. Architecture-level token compression remains a separate T3 candidate, not part of the existing Base execution identity.

The actual data's closed navigation strings (turn left/keep straight/turn right/unknown) have34/34/34/33 tokenizer tokens. All image/special-token spans are fixed by the locked builder;1930 is the observed maximum legal sequence for this closed input domain. We do not extrapolate the memory result to arbitrary free-form prompts. No attention head requests full attention weights, and the language vocabulary projection was already bypassed before this change.

An architectural token compressor would need one per-view resampling layout consistently applied to base visual embeddings and **all three** DeepStack streams, with a new MRoPE/visual-mask/token schema. Arbitrarily cropping image tokens or faking image_grid is not valid. A fair pilot would preserve three1024×576 inputs and all four targets, declare compressed tokens per view and resampler parameters, and train a new identity; old22k states/candidate caches cannot be reused as if equivalent. It is not necessary to start such a new model while execution-layer improvements are still being measured.

A **design-only** T3 budget for a later study is128 latents per view (384 total) instead of576 per view (1728 total), followed by the unchanged Query and auxiliary branches. This would reduce the approximate LLM sequence1930→586; dense sequence-linear work scales to0.304 and idealized sequence-quadratic work to0.092, not measured wall-time guarantees. A shared256-wide cross-attention resampler with2048→256 input and256→2048 output projections, four heads, a1024-wide MLP and three128-token latent tables costs roughly1.95M trainable parameters before adapters for the three DeepStack streams. Whether those streams share the attention assignment or use separate projections is a new modeling decision requiring explicit ablation. A new declared positional/visual embedding layout must replace the raw-grid injection contract; no existing image_grid values can be reused to conceal token removal. This pilot is **not run**, and compression is not an unconditional next step because the B1b execution-only screen already gives a large gain.

Nonreentrant checkpoint recomputation can stop early by an internal exception. Therefore the hook output list contains7 completed forwards for each language layer while the record_function/CUDA region count contains both first-forward and recomputation entries. `MODULE_DTYPE_AND_CALLS.json` reports both; successful-return counts alone must not be used to conclude there was no recomputation.
